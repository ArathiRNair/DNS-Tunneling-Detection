1. Executive Summary

DNS Tunneling is an advanced cyber-attack technique that abuses the Domain Name System (DNS, UDP/TCP port 53) to exfiltrate confidential enterprise data or transmit malicious Command & Control (C2) payloads through standard network firewalls. Because DNS queries are critical for standard internet browsing and network discovery, port 53 is almost universally permitted outward, making it an attractive covert channel for adversaries.

The objective of this research project is to develop an end-to-end Machine Learning pipeline that distinguishes benign domain traffic from malicious DNS tunneling queries by analyzing lexical structure, statistical character distributions, and Shannon Entropy.

Day 1 Objective: Establish a robust, reproducible, and isolated development environment, construct the modular software architecture, configure version control, and confirm that all necessary scientific libraries function without error before building model components.

4. Modular Pipeline Breakdown (src/)

Module Name Future Responsibility Cybersecurity / Academic Value
data_loader.py Ingests training.csv (15,000) and validating.csv (5,000). Loads headerless data, maps Column 0 to Label and Column 1 to Domain name.
preprocessing.py Normalizes domains (lowercasing, trimming root dots, validating strings). Ensures clean, robust text inputs and eliminates corrupted entries.
feature_extraction.py Extracts domain lengths, subdomain counts, digit ratios, consonant-vowel ratios. Translates raw domain queries into numerical features for machine learning.
entropy.py Computes Shannon Entropy: \( H(X) = -\sum P(x) \log_2 P(x) \). Key discriminator: Encoded tunneling payloads show high entropy vs. benign text.
train_models.py Trains classifiers (Random Forest, Logistic Regression) & saves via joblib. Evaluates ensemble learning effectiveness against adversarial evasions.
evaluate.py Calculates Accuracy, Precision, Recall, F1-Score, and Confusion Matrix. Prioritizes high Recall (catching threats) and low False Positives.
explainability.py Computes SHAP (SHapley Additive exPlanations) values and plots. Defeats the "black-box" dilemma by demonstrating why an alert fired.
